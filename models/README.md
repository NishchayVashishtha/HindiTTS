# Trained Model Checkpoints

Place your trained GPT-SoVITS or XTTS model checkpoints here after training completes on Google Colab:

- `SoVITS_weights/`: Put `.pth` files here (e.g., `hindi_sovits_e8.pth`)
- `GPT_weights/`: Put `.ckpt` files here (e.g., `hindi_gpt_e15.ckpt`)

The local inference engine and Streamlit Web UI (`app.py`) will automatically detect these weights and unlock custom cloned voice generation!
